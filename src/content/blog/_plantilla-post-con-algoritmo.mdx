## Primer subtitulo

Contenido en Markdown normal. Parrafos, **negritas**, *cursivas*, listas:

- Item uno
- Item dos
- Item tres

Ojo con caracteres especiales: para escribir `<40 años` o `>200 mg/dL`,
en MDX hay que **escapar** el `<` con `\<`. Ejemplo real:

- Frecuencia cardiaca \<60 lpm sugiere bradicardia sintomatica.
- PA sistolica \>180 mmHg requiere manejo urgente.

Sin escape, MDX intenta parsear `<40` como una etiqueta JSX invalida y el
build falla. Los `>` no dan problemas.

## Como embeber un algoritmo interactivo

Basta con soltar la etiqueta donde quieras que aparezca. Recibe los datos
del algoritmo importados arriba:

<AlgoritmoClinico datos={disneaAguda} />

Si el post es un **caso clinico**, pasa tambien el `slugCaso` para que los
CTAs de nodos terminales lleven al chat con `?caso=&rama=` y el chat sepa
de que caso venimos:

{/* <AlgoritmoClinico datos={disneaAguda} slugCaso="mi-nuevo-caso" /> */}
